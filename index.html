WireGuard Quick Reference

A no-nonsense cheat sheet for setting up a WireGuard tunnel. Copy-paste ready.

1. Generate keys

wg genkey | tee privatekey | wg pubkey > publickey
# pre-shared key (optional, extra layer):
wg genpsk > presharedkey

2. Minimal client config (wg0.conf)

[Interface]
PrivateKey = <CLIENT_PRIVATE_KEY>
Address    = 10.8.0.2/32
DNS        = 9.9.9.9            # encrypted-DNS-capable resolver

[Peer]
PublicKey    = <SERVER_PUBLIC_KEY>
PresharedKey = <PRESHARED_KEY>
Endpoint     = your.server.ip:51820
AllowedIPs   = 0.0.0.0/0, ::/0  # full-tunnel; use 10.8.0.0/24 for split-tunnel
PersistentKeepalive = 25        # helps behind NAT / mobile

3. Bring it up / down

wg-quick up ./wg0.conf      # or: wg-quick up wg0 (if in /etc/wireguard)
wg                          # show live handshake + transfer
wg-quick down wg0

4. Full-tunnel vs split-tunnel

  • Full-tunnel (AllowedIPs = 0.0.0.0/0, ::/0): all traffic, incl. DNS, goes through the tunnel. Best for privacy on untrusted Wi-Fi.
  • Split-tunnel (AllowedIPs = 10.8.0.0/24): only your private subnet is routed; the rest uses your normal connection.
